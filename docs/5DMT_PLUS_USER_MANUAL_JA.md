# 5DMT+ ロボットハンド ユーザーマニュアル

**5MT+ ハンド用 Web 制御システム**

**マニュアル版：** 1.0

**ソフトウェアインターフェース：** バージョン 1.0

> 本マニュアルでは、本製品を **5DMT+** と表記します。Web インターフェース上では、
> モデル名が **5MT+** と表示される場合があります。

---

## 1. 目的と対象読者

本マニュアルでは、クライアント操作者がブラウザベースのダッシュボードを使用して、
5DMT+ ロボットハンドに安全に接続し、状態を監視し、操作する方法を説明します。
本書の対象は通常の日常操作です。設置、配線、修理、およびソフトウェアの保守は、
認定された技術者が行ってください。

## 2. 安全上の注意

ハンドの電源を入れたり動かしたりする前に、このセクションをお読みください。

### 2.1 安全規則

- 人、髪、衣服、装身具、ケーブル、および固定されていない物を、ハンドの可動範囲や
  挟み込みのおそれがある範囲に近づけないでください。
- 操作前にハンドを確実に固定してください。破損、緩み、濡れ、または異常な発熱が
  ある装置を操作しないでください。
- 低い速度と電流から開始してください。用途に応じた試験を行い、負荷上必要な場合に
  限って値を上げてください。
- システムの物理的な電源遮断装置または非常停止装置へ常に手が届くようにしてください。
  Web の **Reset**、**Stop**、および **Logout** は、認証された非常停止装置の代わりには
  なりません。
- ハンドに近づく前に、画面上の接続状態だけで安全と判断しないでください。最初に電源と
  蓄積された機械エネルギーを遮断してください。
- 予期しない動作、フィードバックの消失、異常な温度上昇、または異音が発生した場合は、
  操作を中止してください。電源を遮断し、サポート窓口へ連絡してください。
- ハードウェアに指定された定格可搬質量、デューティサイクル、使用環境条件、または
  電気定格を超えないでください。
- シリアル接続設定を変更できるのは、訓練を受けた管理者だけです。

### 2.2 毎回の操作前点検

1. 指部、取り付け状態、ケーブル、および作業領域を点検します。
2. 障害物を取り除き、安全な立入禁止区域を設けます。
3. 物理的な電源遮断装置へ手が届くことを確認します。
4. 設置担当者の指示に従ってハンドとコントローラーを接続します。
5. コントローラーの電源を入れ、動作を指令する前にダッシュボードの接続状態とライブの
   フィードバックを確認します。
6. 負荷のない状態で速度と電流を低く設定し、**Open All** をテストします。

## 3. 必要なもの

- 操作者の端末と同じネットワークに接続された、設置済みの 5DMT+ ハンドおよび
  コントローラー。
- JavaScript が有効な最新のデスクトップまたはモバイルブラウザー。
- 管理者から提供されたダッシュボードのアドレスとユーザー認証情報。
- Hand Tracking を使用する場合は、カメラの使用許可と安全なブラウザー接続
  （HTTPS または `localhost`）。

5DMT+ Web ダッシュボードのアドレスは次のとおりです。

`https://192.168.0.210:8080/`

初回アクセス時、自己署名証明書に関する警告がブラウザーに表示される場合があります。
アドレスが `https://192.168.0.210:8080/` であることを確認し、管理者の指示に従って
接続を許可してください。

操作者の端末は、5DMT+ コントローラーと同じネットワークに接続されている必要があります。
管理者の承認なしに、コントローラーの IP アドレスやネットワーク設定を変更しないでください。

## 4. サインインとダッシュボードの概要

1. ブラウザーで `https://192.168.0.210:8080/` を開きます。
2. ログインページが表示されない場合は、`https://192.168.0.210:8080/login.html` を
   直接開きます。
3. 割り当てられたユーザー名とパスワードを入力し、**Login** を選択します。パスワード欄で
   **Enter** キーを押して送信することもできます。
4. ダッシュボードに、想定したサインイン済みロールとハンドタイプが表示されていることを
   確認します。

認証情報は設置場所ごとに異なります。認証情報を共有しないでください。操作者の端末から
離れるときは、必ず **Logout** を選択してください。ブラウザーのタブを閉じることは、
ロボットを安全に停止する方法ではありません。

### 4.1 アクセスロール

| ロール | 一般的なアクセス範囲 |
| --- | --- |
| Guest | 監督下での基本操作に使用する Manual Control および Live Status |
| Operator | Guest の機能に加え、Script Editor、Script Runner、および Hand Data |
| Administrator | Hand Tracking／記録、Settings、およびダッシュボードの Reset を含むすべての機能 |

アクセス範囲は、インストール済みのソフトウェア設定によって決まります。必要なメニューが
表示されない場合は、ロール制限を回避しようとせず、管理者へ連絡してください。

### 4.2 ダッシュボードの表示と操作

- **Connection** は、Web アプリケーションがロボットハンドのサービスへ到達できるかを
  示します。`ONLINE` と表示されても、動作が安全であることを保証するものではありません。
- **Hand Type** は、選択中の製品プロファイルを示します。設置担当者から別の指定がない限り、
  5DMT+ ハンドには **5MT+** を選択してください。
- **Web Server** には通常、ポート `8080` が表示されます。
- **Mode** は、準備完了やリセットなど、ダッシュボードの動作状態を示します。
- 言語選択では **English** と **Japanese** を選択できます。
- **Reset Robot** は、コントローラーのリセットを要求します。周囲の安全を確保してから
  使用してください。非常停止としては使用できません。

## 5. クイックスタート：手動操作

1. セクション 2.2 の操作前点検を完了します。
2. サインインし、**Connection: ONLINE** であることを確認します。
3. **Manual Control** を選択します。
4. 最初のテストでは、**Speed** と **Current** を低い値に設定します。
5. **Open All** を選択し、障害物に接触せず滑らかに動くことを確認します。
6. ハンドと `P`、`C`、`T` のフィードバック値を観察しながら、1 本の指のスライダーを
   ゆっくり動かします。
7. 終了時は **Open All** を選択し、機構を安全な状態にして、設置場所で定められた
   シャットダウン手順に従います。

## 6. Manual Control（手動制御）

コマンドパケットには、速度、電流、および 6 個のモーター位置が含まれます。スライダーを
動かすとロボットへ指令が送信されます。スライダーをシミュレーションやプレビューとして
扱わないでください。

### 6.1 操作項目

- **Speed：** 指令速度（1～255）。
- **Current：** 指令電流（1～255）。値を上げると力や発熱が増える場合があります。
  有効な範囲で最も低い設定を使用してください。
- **指スライダー：** Thumb、Index、Middle、Ring、Little、および Thumb Abduction の
  位置を個別に調整します。
- **Sync：** Sync ボックスが選択された指は、選択中の指を調整すると連動して動きます。
  スライダーを動かす前に、意図したグループになっていることを確認してください。
- **Open All：** 6 個すべてのモーターを開位置へ動かします。
- **Close All：** モーターを設定済みの閉位置へ動かします。使用前に閉動作範囲全体から
  障害物を取り除いてください。
- **Reset：** ロボットのリセットを要求します。実行後、接続状態と位置フィードバックを
  再確認してください。

### 6.2 フィードバック

各モーターカードには、次の値が表示されます。

- `P` — 報告された位置
- `C` — 報告されたモーター電流
- `T` — 報告された温度（摂氏）

画面下部のステータス行には WebSocket の接続状態が表示されます。**WS not connected** と
表示された場合は、指令の送信を中止し、機構を安全な状態にして、セクション 12 の
トラブルシューティングを実施してください。

## 7. Live Status（ライブ状態）

**Live Status** は、6 個すべてのモーターを監視する読み取り専用画面です。

1. **Live Status** を開き、ステータスが **Live ON** に変わることを確認します。
2. ライブの位置、電流、および温度カードを確認します。
3. 左右のコントロールを使用して、表示する履歴範囲を調整します。
4. 必要に応じてチャートをパンまたはズームします。**Reset Zoom** を選択すると、
   チャート表示が元に戻ります。

値が更新されない、空欄である、または明らかに不自然な場合は、フィードバックが失われた
ものとして扱ってください。作業を安全に停止し、接続状態を調査してください。

## 8. Script Editor（スクリプトエディター）

スクリプトは、**Move** コマンドと **Wait** コマンドを順番に並べたものです。

### 8.1 スクリプトの作成と保存

1. **Script Editor**、**Create New** の順に選択します。
2. **+ Move** を選択します。速度、電流、および 6 個の目標位置を設定してから、
   コマンドを確定します。
3. 必要な箇所で **+ Wait** を選択し、待機時間を追加します。
4. または、**+ Current Pos** を選択すると、現在のフィードバック位置が Move コマンドとして
   追加されます。
5. 行を選択して、**Edit**、**Duplicate**、**Delete**、**Up/Down**、または **Run Line** を
   実行します。
6. **Run Line** は、選択した行だけを実行しても安全であることを確認してから使用してください。
   それより前の準備動作は自動実行されません。
7. **Save** を選択し、分かりやすく一意な名前を入力して、スクリプト選択欄に表示されることを
   確認します。

直前の動作が安定するまで十分な Wait ステップを設定してください。次のコマンドの実行が
早すぎると、予期しない軌道や過大な負荷が発生するおそれがあります。

### 8.2 スクリプトのテスト

1. 障害物を取り除き、低い速度／電流から開始します。
2. 管理された環境で **Run Line** を使用し、各動作をテストします。
3. 物理的な停止装置／遮断装置のそばで待機したまま **Run** を選択し、シーケンス全体を
   テストします。
4. 確認済みのシーケンスと異なる動作をした場合は、直ちに **Stop** を選択します。

**Delete** を実行すると、選択中の保存済みスクリプトが完全に削除されます。削除前に名前を
確認し、必要なバックアップを保存してください。

## 9. Script Runner（スクリプト実行）

Script Runner では、簡単な操作でスクリプトを実行し、状態をライブ監視できます。

1. 一覧から保存済みスクリプトを選択し、表示されるすべての行を確認します。
2. 作業範囲から障害物を取り除き、周囲の人に注意を促します。
3. **Run** を 1 回だけ選択します。要求の開始中は繰り返しクリックしないでください。
4. 実行中は、強調表示されるコマンドとライブフィードバックを継続して監視します。
5. 操作を中止する必要がある場合は **Stop** を選択します。ソフトウェアによる制御が失われた
   場合は、設置場所の物理的な電源遮断装置または非常停止装置を使用してください。

変更する場合は **Script Editor** に戻ってください。実行中の可能性があるシーケンスを
変更しないでください。

## 10. Hand Tracking とスクリプト記録

Hand Tracking は、カメラで検出した指の位置をロボットの指令へ変換します。これは管理者向けの
高度な機能であり、直ちに動作が始まる場合があります。

1. ロボットの周囲を安全にし、**Settings** でトラッキングの速度と電流を低く設定します。
2. **Hand Tracking** を開き、front、back、または番号付きの Web カメラを選択します。
3. 求められたらカメラの使用を許可します。明るさが均一で背景が整理された場所で、
   1 つの手だけがはっきり映るようにします。
4. **Start** を選択し、動作に使用する前に、ランドマークと 6 本の位置バーが操作者の手に
   追従することを確認します。
5. 表示の向きが適切でない場合は **Mirror** を選択します。
6. 動作シーケンスを記録するには **Record** を選択します。カウントダウン後、ゆっくりと
   意図どおりに手を動かします。
7. **Stop** を選択すると記録を停止して保存します。再実行する前に、生成されたスクリプトを
   Script Editor で確認します。
8. ページから移動する前にトラッキングを停止します。

キーボードショートカットは、トラッキングの開始／停止が `T`、記録が `R`、停止して保存が
`Space` です。別のブラウザー操作部にフォーカスがある場合や、キーボード操作が不確かな場合は、
画面上の操作部を使用してください。

カメラトラッキングは、遮蔽、反射、暗さ、複数の手、カメラの遅延、およびネットワーク遅延の
影響を受ける場合があります。安全性が重視される動作には使用しないでください。

## 11. Hand Data と Settings

### 11.1 Hand Data

有効なハンドのフィードバックを受信している間、システムは時刻付きの位置、電流、および
温度サンプルを記録します。**Hand Data** では、次の操作を行います。

1. **Refresh** を選択してファイル一覧を更新します。
2. ファイルを選択し、記録データを表示します。
3. 運用手順で必要とされるグラフと詳細を確認します。
4. ファイル名を確認してから **Delete File** を使用してください。画面上で削除したファイルは
   元に戻せません。

記録は診断用データであり、安全ログまたは認証された測定値ではありません。

### 11.2 Settings（管理者）

Settings ページには、次の設定があります。

- カメラタイプおよびカメラインデックス
- トラッキングの速度および電流
- シリアルデバイスのキーワード、ボーレート、タイムアウト、および再試行間隔
- デフォルトの速度、デフォルトの電流、および送信間隔

変更前に既存の値を記録してください。**Save Settings** を選択した後、状態を確認し、低出力で
動作テストを実施します。このページの **Reset** は保存済み設定を再読み込みするものであり、
工場出荷時の値に戻すとは限りません。シリアル設定が誤っていると通信不能になる場合があり、
過大な指令値は装置の破損や危険につながるおそれがあります。

## 12. トラブルシューティング

| 症状 | 安全な対処方法と確認事項 |
| --- | --- |
| ダッシュボードが開かない | 操作者の端末が 5DMT+ コントローラーと同じネットワークに接続されていることを確認し、`https://192.168.0.210:8080/` を開きます。初回アクセス時に証明書の警告が表示された場合は、アドレスが正しいことを確認し、管理者の指示に従って接続を許可してください。接続できない場合は、ネットワーク、コントローラーの電源、および Web サービスの状態を確認し、解消しない場合は管理者へ連絡します。 |
| ログインが拒否される | 大文字／小文字とキーボード配列を確認してから、認証情報について管理者へ問い合わせます。パスワードを繰り返し推測しないでください。 |
| ダッシュボードに OFFLINE と表示される | 動作を指令しないでください。コントローラーの電源とネットワーク接続を確認し、再接続を待ってから 1 回更新します。解消しない場合は管理者へ連絡します。 |
| Manual Control に WS not connected と表示される | 操作を中止してハンドから離れ、ページを再読み込みし、ダッシュボードの状態を確認します。フィードバックが再開しない場合は、物理的な安全停止手順を実施します。 |
| ハンドが動かない | 正しいハンドプロファイル、接続状態、およびゼロ以外の設定値を確認します。通電中は可動範囲に入らず、コントローラーの故障や障害物の有無を確認します。すぐに電流を最大にして対処しないでください。 |
| 動作が逆方向または予期しないものになる | 使用可能な場合は Stop、または物理的な安全停止方法を使用します。電源を遮断し、使用したスクリプト／設定を保存して、再試行前にサポート窓口へ連絡します。 |
| フィードバックが空欄または更新されない | ロボットの状態が不明なものとして扱います。安全に停止してデータ接続を確認し、エネルギーを遮断するまで近づかないでください。 |
| 温度または電流が予期せず上昇する | 動作を停止し、設置場所の手順に従って電源を遮断します。冷却後、負荷、障害物、機構、および設定の点検を依頼します。 |
| カメラが起動しない | HTTPS または `localhost` を使用し、ブラウザーでカメラの使用を許可します。カメラを使用中の他のアプリを閉じ、一覧から別のカメラを選択します。 |
| トラッキングが不安定 | トラッキングを停止します。照明／背景を改善し、遮られていない 1 つの手だけを映し、カメラを固定して、低い設定で再試行します。 |
| スクリプトが見つからない | スクリプト一覧を更新し、名前を確認します。このコントローラーに保存したものであることを確認します。 |
| Stop ボタンが反応しない | 物理的な非常停止装置または電源遮断装置を使用してください。ブラウザーやネットワークの復旧を待たないでください。 |

## 13. 通常のシャットダウン

1. トラッキング、記録、または実行中のスクリプトを停止します。
2. 安全に実行できる場合は、ハンドを設置場所で指定された安全位置／開位置へ移動します。
3. 動作が停止したことを確認します。
4. **Logout** を選択します。
5. 設置場所のシャットダウン手順に従い、コントローラーとアクチュエーターの電源を遮断します。
6. 異常な温度、摩耗、または破損がないか点検し、問題があれば報告します。

## 14. サポート情報

供給元またはシステム管理者へ連絡する前に、次の情報を記録してください。

- コントローラーのアドレス、表示中のハンドタイプ、サインイン中のロール、および使用中のページ
- 日時、およびステータスやエラーメッセージの正確な内容
- 問題が発生する直前に行った操作
- 関係するスクリプト名およびデータファイル名
- 位置／電流／温度のライブフィードバックが変化していたかどうか
- 必要に応じて、ブラウザー／端末の種類および選択したカメラ

パスワードを送信しないでください。許可を受け、システムのエネルギーを安全に遮断した場合を
除き、ハンドの分解や配線の変更を行わないでください。
